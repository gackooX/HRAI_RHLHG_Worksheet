HOT2000 Version 8 - Program documentation

The following is a list of the BASESIMP systems currently implemented in
HOT2000.  The first 67 systems are as documented in

BASESIMP, A Simplified Foundation Energy-Loss Model Derived from
          BASECALC (TM) Simultions
Ian Beausoleil-Morrison, CANMET Energy Technology Centre,
Natural Resources Canada, Draft May 17, 1996.

Systems  68-72  were added in 1998.
Systems  73-120 were added in August, 1999.
         (A pdf file documents all current systems)
Systems 121-145 were added in December, 1999

The configuration #'s are used in HOT2000 to reference tables of heat-loss
coefficients.  For example, to specify Configuration: #  2   = BCIN_2 for
the first foundation, set

 BSMT96.iFndatn[10][0] = 2
